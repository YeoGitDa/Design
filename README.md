## 2. 글꼴 — Pretendard

| 소제목 | SemiBold(600) | 20pt | 18px |

## 3. 모양
- 둥근 직사각형 — 모서리 16px (PPT 는 도형 크기 대비 ❓)
- 버튼·배지는 알약형(완전 둥글게)
- 투명도 93% — ❓대상 확인 후 기입
- 그림자는 아주 옅게 하나만

## 4. 캐릭터 (곰)

- 곰 원본: Web_page `public/backend/image/` (gomdol.jpg · mascot_chatbot.png)
- 소품(헤드셋·모자 등)은 자유, 몸 색·얼굴 모양은 바꾸지 않음
